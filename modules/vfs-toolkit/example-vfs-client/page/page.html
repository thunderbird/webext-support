Testing the VFS Toolkit

The following buttons open the file pickers of the VFS Toolkit available for WebExtensions. It is a wrapper for OPFS implemented by Mozilla, which is a virtual file system, but sadly without file pickers.

This gap is closed by the VFS Toolkit. In addition, the VFS Toolkit provides support for arbitrary storage backends, and is not limited to OPFS. Users can install additional providers.

The only already available storage backend is the Local Home Folder Access Provider, allowing access to your local home directory via Native Messaging (not via Experiments!).
