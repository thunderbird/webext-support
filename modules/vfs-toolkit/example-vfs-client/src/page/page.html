Testing the VFS Toolkit

The following buttons test the file pickers of the VFS Toolkit, a WebExtension framework for file access across multiple storage backends. Users can pick whatever storage backend they prefer by installing additional provider add-ons.

The picker of this example client implementation provides a test framework for add-on developers to test their provider add-ons against the VFS Toolkit API. The test can be triggered for the currently selected connection by clicking on the flask icon in the picker's toolbar.

The following providers are available:

OPFS (built-in default) Origin Private File System — a virtual file system provided by Mozilla, used as the default storage inside the WebExtension. All stored files are cleared when the add-on is uninstalled.
VFS-Provider: WebDAV A shared WebDAV account manager. Other add-ons that need access to a WebDAV file storage can ask this provider to set up and manage the connection on their behalf. Works with ownCloud, Nextcloud and many other WebDAV-based cloud services.
VFS-Provider: Local Home Folder Access Enables access to the user's local home folder through a native messaging helper application (Python 3 required). Not via Experiments!
